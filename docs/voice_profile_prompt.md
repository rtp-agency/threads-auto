# Промпт для построения Voice Profile (ТЗ п.5)

Разовая ручная операция при онбординге. Выполняется через Claude Code / чат
с Claude, **не** через API сервиса.

## Порядок

1. `scripts/fetch_threads_archive.py` → `threads_archive.json` (весь архив
   постов: текст + метрики + дата).
2. Скормить Claude файл целиком вместе с промптом ниже.
3. Вычитать и скорректировать результат вручную.
4. Отобрать 3-5 дословных (verbatim) постов-примеров → `examples.json`.
5. `scripts/save_voice_profile.py --profile voice_profile.md --examples examples.json`.

Скриншоты-мокапы (архетип meme_notification) в анализ голоса **не включать** —
это не органический текст со стилем; формат описывается отдельно.

Повторная генерация — по запросу клиента, если стиль «уходит» со временем.

## Промпт

```
Ниже — полный архив Threads-постов клиента (JSON: текст,
метрики, дата). Твоя задача — НЕ переписывать посты, а ОПИСАТЬ его голос так,
чтобы по этому описанию другая модель могла писать неотличимые посты.

Опиши:
1. Длину и ритм предложений (короткие рубленые / длинные, как чередуются).
2. Регистр: сленг, суржик, мат — что именно использует и как часто, дословные
   примеры характерных словечек и оборотов.
3. Структуру постов: как строится хук, как разворачивается история, как
   формулируется вопрос к аудитории в конце.
4. Пунктуацию и оформление: тире/скобки/капс/эмодзи/переносы строк.
5. Темы и позицию: о чём пишет, как относится к ученикам, что провоцирует.
6. Чего в голосе НЕТ (чтобы модель не добавляла лишнего).

КРИТИЧЕСКИ ВАЖНО: не сглаживай резкость, сленг и мат до вежливого
корпоративного тона. Если автор пишет жёстко и с матом — так и опиши, с
дословными примерами. Твоя задача — точность, а не приличие.

Отдельно выпиши 5 дословных постов с лучшим engagement (лайки+комменты+репосты
относительно просмотров) — они пойдут в few-shot примеры без изменений.
```
